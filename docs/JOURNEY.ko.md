# 이 스킬을 어떻게, 왜 이렇게 만들었나

[English](JOURNEY.md) | 한국어

## 0. 문제

[@geono_x](https://www.instagram.com/geono_x/)는 토크 포맷이야. 아이폰 한 대가 나를 고정으로 찍고(나는 질문),
친구 정우는 맞은편 화면 밖에서 설명해. 정우가 말할 때는 정우 캐릭터가 화면에 나오고, 한국어 자막 아래에 작은
영어 자막이 붙어. 3–5분 촬영본이 90초 안팎 릴스가 돼.

기획과 촬영은 금방 끝나. 오래 걸리는 건 편집이고, 그중 대부분이 **컷편집**(문장이 진짜 시작하고 끝나는 지점 찾기,
추임새와 말 더듬은 부분 빼기, 턴 간격 맞추기)과 **자막**(한 절씩 끊어서 달고, 영어 한 줄 더 달기)이야.

"내 스타일"의 기준은 9번 「트럼프 전쟁」이야. [내가 CapCut으로 직접 편집한 릴스](https://www.instagram.com/reel/DeIZ4g9J8vI/)고,
CapCut 프로젝트는 평문 JSON 드래프트로 저장돼서 눈대중이 아니라 컷 경계, 구간별 배속, 자막 폰트·크기·위치·색,
캐릭터 타이밍을 그대로 읽을 수 있었어. 이게 `ref/style_spec.md`와 정답 데이터 `ref/gt9.json`이 됐어.

## 1. v1 — 에이전트 3팀 대결 (2026-10-21)

처음엔 에이전트끼리 경쟁시켰어. 세 팀이 같은 브리프(내 요구사항, 측정한 스타일 스펙, 이탈 방지 리서치, 9번 원본 +
내 최종본, 10번 원본)를 받아서 각자 스킬을 통째로 만들었어. 채점 기준:

1. **9번 자동 점수**(`ref/evaluate.py`, 95점 만점): 내 편집과의 컷 일치도(원본 타임라인 F1, 말하는 중간에 자르지
   않기), 속도, 자막 내용과 형식, 화자·캐릭터 정확도, 렌더 규격, 음량.
2. **10번 심사 점수**: 심사 에이전트가 각 팀의 10번 렌더(같은 구도, 새 내용)를 보고 자막 정확도, 컷 품질, 스타일
   충실도, 이탈 방지 장치, 보정, 오디오를 평가.
3. **스킬 품질**: 다른 에이전트가 SKILL.md만 보고 실제로 따라 할 수 있는가.

2라운드로 진행했어(2라운드는 각 팀이 점수를 보고 개선). 1라운드 C 82.1, A 80.4, B 78.7, 결승 **C 83.5** vs A 81.3.
우승 스킬의 9번 점수는 75.7이고, 같은 채점기로 내 편집은 93.9야(자막 내용 점수는 원래 낮아. 나는 자막 달 때
말을 다듬어서 쓰거든).

v1은 아이폰 HLG 원본에서 **전부** 했어. 색보정, 피부 보정, 얼굴 슬림, 음성 체인, 줌, 플래시 전환, 카드, 캐릭터까지.

## 2. 뭐가 문제였나 — v1에 대한 내 피드백

미리보기를 보면서 하나씩 피드백했고, 하나하나가 규칙이나 수정이 됐어.

| 피드백 | 원인 | 수정(지금 규칙) |
|---|---|---|
| "배속이 조금 빠르다" | 평균 1.33배 | 나 1.20 / 정우 1.30 / 섞임 1.25, 최대 1.32 |
| "정우와 내 텀이 너무 짧아" | 턴이 0.05초 수준으로 붙어 있었음 | 화자가 바뀔 때마다 무음 0.20초(자연스러운 대화 턴 간격 ≈ 200ms). 실제 무음으로 늘리고, 안 되면 다음 컷을 3% 음량으로 미리 깔기 |
| "줌 하는 게 어색해" | 컷 중간 줌, 정우 대사에도 줌 | 1.08배를 **내 대사(검정 자막)가 시작되는 컷**에서만 하드컷으로, 다음 컷에서 해제. 문장 중간·정우 대사엔 없음, 8초에 1번 이하 |
| "얼굴 보정이 부자연스럽다" | 부위별 얼굴 슬림 | 삭제하고 머리 크기 균일 3.5% 축소만 |
| "정우가 말할 때 내 목이 깨져" | ffmpeg 4.4 `remap`이 최근접 보간 + 4:2:0↔4:4:4 변환 | 파이프로 `cv2.remap` 쌍선형 워프 |
| "'지금 쓰는 클로드도 할 수 있지 않나?'를 맨 앞 훅으로, 전환은 자연스럽게" | — | 여러 구간 콜드오픈 + 본편은 그냥 하드컷(플래시·효과음은 싸 보여서 요청할 때만) |
| "영어 자막은 한국어 자막 기반으로" | 영어를 오디오에서 따로 써서 자막과 어긋남 | 영어 = **확정된 한국어 자막**을 1:1 번역, 타이밍 동일 |
| "소리가 작아" | 원본이 −41 LUFS 수준 | 목표 음량까지 게인 탐색 + 리미터, 결과물에서 다시 측정 |

그리고 전체를 테스트해본 솔직한 결론은 **그래도 어색하다**였어. 자동으로 넣은 작은 "개선"들이 쌓이니까 내 편집처럼
안 보였어.

## 3. v2 — 병목 중심으로 재설계 (2026-10-22)

세 가지를 보고 설계를 바꿨어.

1. **보정은 CapCut이 빠르고 더 좋다.** 음성, 얼굴, 색, 선명도 보정은 CapCut 툴로 2분이면 끝나. 재현이 어디까지
   되는지도 재봤어. 원본→보정본 25프레임 쌍으로 3D LUT를 학습하니 배경 색 오차가 8.8 → 2.75 /255, 얼굴 톤이
   10.6 → 6.1 /255까지 줄었어. CapCut의 85–90% 수준이야. 꽤 가깝지만 CapCut 얼굴형 툴은 재현이 안 되고, 2분은
   병목이 아니야. 그래서 이제 입력은 **CapCut 보정본**이고, 그대로 써(색 재보정 없음, 음량만 맞춤). 원본에서
   보정을 재현하는 건 *선택* 단계 R로 남겨뒀어.
2. **시간이 드는 곳에만 AI**: 컷, 그다음 자막. 나머지는 전부 선택이고, 티 나면 안 돼.
3. **한 번에 끝내기 대신 승인 단계.** 완성본을 고치는 것보다 컷을 승인하는 게 낫더라. 미리보기마다 타임코드를
   찍어서 "37초 컷 어색해"가 바로 원본 시간으로 연결되게 했어.

결과는 **에이전트 하나가 순서대로 따라가는** 단계형 워크플로우야. (멀티 에이전트는 *만들 때*는 좋았어. 대결에서
좋은 규칙이 빨리 나왔거든. 근데 *돌릴 때*는 명확한 절차를 따르는 에이전트 하나가 더 안정적이야.)

```
0 인테이크 → 1 컷 ─승인→ 2 자막(한 → 영) ─승인→ 3 연출(선택) → 4 검수 서브에이전트 → 5 4K 마스터
```

### 검수 에이전트를 따로 두는 이유

편집한 에이전트는 자기 계획을 믿어. 검수 에이전트는 렌더된 영상과 EDL 타임코드만 받아서, *결과물* 오디오를 다시
인식하고, 자막마다 들리는 말과 비교하고, 영어 줄을 한국어 줄과 대조하고(특히 숫자), 컷·줌·카드마다 프레임을 뽑고,
프레임 차이와 위상 상관으로 튐·흔들림을 찾고, 컷 지점 클릭, 무음, 음량, 검은/멈춘 프레임, 겹침을 확인해.
10번 1라운드에서 영어 숫자 오류("move the wedding up a year", 실제는 3년 뒤 → 내년), 다음 단어를 0.1초 먹은 컷,
타이트한 컷 뒤 25ms 잔음, 0.84초 무음을 찾았어. 계획만 봐서는 내가 못 잡았던 것들이야. 2라운드 blocker 0.
[`examples/ep10/qa_round1_findings.json`](../examples/ep10/qa_round1_findings.json) 참고.

## 4. 수치의 근거

| 규칙 | 근거 |
|---|---|
| 자막 형식(16자 이하, 한 절, 0.45초 이상, 초당 13자 이하), 박스 크기·위치 | 9번 CapCut 드래프트에서 측정 |
| 배속 1.2–1.32 | 9번(1.2–1.4) + "조금만 늦춰" 피드백 |
| 턴 간격 0.20초 | 대화 분석 연구의 턴 간격(~200ms) + 피드백 |
| 0.28초 이상 무음에서만 자르기, 여유 0.09 / 0.12초, 12ms 페이드 | 자음 잘림·클릭 방지 (검수로 확인) |
| 줌 8–10초에 1번 이하, 하드컷만, 플래시·효과음 없음 | 이탈 방지 리서치([`ref/retention_research.md`](../skills/reels-talk-edit/ref/retention_research.md)) + 피드백 |
| 카드 15–20초에 1개 이하, 실제로 말한 숫자만 | 리서치 + "화면에 없는 사실 금지" |
| 단어별 카라오케 자막, 이모지 없음 | 내 스타일 + 가독성 리서치 |

## 5. 테스트

- **9번(내 편집)** = 회귀 테스트. 규칙을 바꾸면 9번을 다시 계획하고 `ref/evaluate.py`로 채점해. 1점 넘게 떨어지면 회귀야.
- **10번** = 같은 날, 같은 구도, 다른 내용(GPT-6). 283.5초 → 97.3초, 34컷, 한·영 자막 58개, 콜드오픈 훅
  "AI 전문가인 척하기". 전체 계획은 [`examples/ep10/plan.json`](../examples/ep10/plan.json).
- **다음**: 다른 구도(다른 자리 배치, 카메라 2대)에서 어떤 규칙이 포맷 전용인지 확인할 예정.

## 6. 자기 포맷에 맞게 고칠 때

- 먼저 자기가 완성한 편집본을 측정해(CapCut 드래프트는 JSON이야). 자기 작업에서 뽑은 규칙이 일반론보다 나아.
- 편집 판단은 Claude가 plan 파일에 적게 하고, 스크립트는 결정적으로 유지해. 그러면 수정이 전부 한 줄이야.
- 컷 다음에 승인 단계를 둬. 제일 중요한 결정이고, 바꾸는 비용이 제일 싸.
- 첫 번째 에이전트를 믿지 않는 두 번째 에이전트가 결과물을 듣게 해.
